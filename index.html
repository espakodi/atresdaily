Cómo instalar

Desde repositorio (recomendado — recibe actualizaciones automáticas)

  1. En Kodi: Ajustes → Explorador de archivos → Añadir fuente.
  2. En <Ninguno> introduce esta dirección exacta:

    https://espatv.github.io/atresdaily/
    Importante: la URL debe terminar en .io/atresdaily/. La URL acabada en .com no sirve.
  3. Ponle de nombre atresdaily y pulsa OK.
  4. Ve a Add-ons → icono de paquete (esquina superior izquierda) → Instalar desde archivo zip.
    (Si aparece el aviso de seguridad: Ajustes → Sistema → Add-ons → activar "Orígenes desconocidos").
  5. Selecciona la fuente atresdaily → repository.atresdaily-1.0.1.zip.
  6. Cuando aparezca la notificación "Add-on instalado", ve a Instalar desde repositorio → AtresDaily Repository → Add-ons de vídeo → AtresDaily → Instalar.

Desde ZIP (instalación manual sin actualizaciones automáticas)

  1. Descarga el .zip desde https://espatv.github.io/atresdaily/.
  2. En Kodi: Add-ons → icono de paquete → Instalar desde archivo zip → selecciona el archivo descargado.
